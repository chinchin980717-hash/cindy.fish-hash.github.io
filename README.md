# 《我是魚》暈船模擬器

一款以聊天訊息為情境的關係判斷遊戲。遊戲提供 Godot 4 桌面／匯出版本與 GitHub Pages 靜態網頁版本，兩者共用 `questions.json` 中的 250 題繁體中文題庫。

## 遊戲規則

玩家先閱讀對方傳來的情境，再從三段完整文字回覆中選一句。選擇後才揭曉魚的動作（咬餌、觀察或脫鉤／甩尾離場）與心動、警覺、界線數值變化。文字回覆才是選項，魚的行動只是結果；題庫沒有預先指定的唯一「最佳答案」。

可選 5、8、10、15、30、60、100 題短局（隨機抽題），或選擇 250 題依題庫順序完成完整航程。完整航程會從第 1 題一路玩到第 250 題。

## 專案內容

- 版本：`2.8.0`
- `index.html`、`styles.css`、`game.js`：GitHub Pages 瀏覽器版
- `project.godot`、`main.tscn`、`main.gd`：Godot 4 專案
- `questions.json`：兩個版本共用的 250 題資料，含情境及每題三段文字回覆和對應的魚動作
- `「我是魚」暈船模擬器250題完整題庫.txt`：使用者提供的原始題庫文字
- `PROJECT.md`：專案架構、資料格式與接手說明

## 執行

瀏覽器版部署於 GitHub Pages；在本機測試時，請從專案資料夾啟動 HTTP 伺服器後開啟頁面（題庫透過 `fetch("questions.json")` 載入，不能直接以 `file://` 開啟）。Godot 版可用 Godot 4 開啟專案根目錄的 `project.godot`。

鍵盤操作：`1 / 2 / 3` 選擇三段回覆、`Enter / Space` 開始或進入下一題、`Esc` 返回標題。
