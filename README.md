# cindy.fish-hash.github.io

## 《我是魚》

這是一個以聊天訊息為魚餌的關係判斷遊戲，使用 Godot 4 GDScript 製作。玩家每回合閱讀一則訊息，選擇咬餌、先觀察，或甩尾離場，並觀察自己的心動值、警覺值、連擊與分數。

目前的主要程式碼在 [`main`](./main)，完整的專案背景、遊戲結構、延伸規劃與其他帳號的接手方式，請閱讀 [`PROJECT.md`](./PROJECT.md)。

## 目前內容

- 版本基準：`2.7.0`
- 深海主題的標題、遊玩與結算畫面
- 5／8／10／15 題的回合選擇
- 超過 200 則聊天情境
- 界線值、每回合短評與結算游法報告
- 鍵盤快捷鍵：`1 / 2 / 3`、`Enter / Space`、`Esc`

## 注意

目前儲存庫保存的是可閱讀的 GDScript 原始碼與專案文字文件，尚未包含完整的 `project.godot`、場景檔或 GitHub Pages 網頁入口。因此其他帳號可以先閱讀、審查與延伸內容；若要在 Godot 4 執行，請依照 [`PROJECT.md`](./PROJECT.md) 的接手說明建立或掛載主場景。
